# 의견 접수와 사용 기록 (프리뷰)

사용자 화면과 2027 준비지도 오른쪽 아래의 ‘개선 의견 보내기’에서 의견을 받습니다. 접수 전 의견 및 임시 세션 저장 동의를 받으며, 연락처 입력이나 개별 답변은 제공하지 않습니다. 의견은 기존 Google Sheets `events` 탭에 `feedback_submit` 유형으로 저장합니다. `meta`에는 종류, 화면, 의견 본문만 넣습니다.

화면·기능 사용 기록도 같은 탭에 저장합니다. 브라우저 탭이 유지되는 동안 생성된 임시 세션 ID를 사용하며, 검색어 원문·IP·브라우저 식별 정보·연락처는 애플리케이션의 행동 기록에 보내지 않습니다. 리드를 별도로 등록하면 기존 `leads` 탭의 세션 ID와 연결될 수 있으므로 완전한 익명 데이터로 취급하지 않습니다.

| 이벤트 | 뜻 | 추가 데이터 |
| --- | --- | --- |
| `page_view` | 화면 방문 | home / prep-map |
| `survey_start`, `survey_step` | 진단 시작·다음 단계 | 단계 번호 |
| `result_view` | 맞춤 결과 확인 | 확인된 공고 수 |
| `search`, `filter_change` | 검색·분야 필터 사용 | 결과 수 / 선택 분야, 검색어 제외 |
| `notice_click`, `notice_save` | 공고 원문 열기·저장 | 공고 ID |
| `feedback_open`, `feedback_submit` | 의견 창 열기·접수 | 접수 때만 의견 본문 |

관리자 CRM은 최근 의견 100건, 최근 7일 이벤트 유형별 건수와 이용 세션 수, 최근 이용 기록을 표시합니다. 관리자 인증 후 ‘기록 CSV 다운로드’로 전체 `events` 탭을 내려받을 수 있습니다. CSV에는 의견 본문과 세션 ID가 들어 있으므로 외부 공유에 주의해야 합니다.

현재는 기존 `events` 탭을 재사용하므로 별도 시트 생성이나 환경변수 추가가 필요 없습니다. 실제 접수·기록은 Google Sheets 연결이 활성화된 배포에서만 성공합니다. 저장 실패 시 의견 창에 오류를 표시하며, 행동 기록 실패는 사용자 흐름을 막지 않습니다. 보존 기간과 삭제 절차는 정식 출시 전에 운영 정책으로 확정해야 합니다.
