# 사업기회 레이더 데이터 검증 (2026-09-20)

## 3개년 준비지도

- 원자료: 중소벤처기업부 `중소기업지원사업목록` 공개 CSV의 2024-03-31, 2025-03-31, 2026-09-01 판본. [공공데이터포털 원자료](https://www.data.go.kr/data/3034791/fileData.do)
- 2023~2025년 신청 시작일을 가진 행을 선택하고 상세 URL로 중복 제거. 같은 사업의 별도 추가모집은 서로 다른 URL이면 별도 공고로 계산.
- 재집계 결과: 2023년 10,214건, 2024년 9,669건, 2025년 13,121건, 총 33,004건. 3년 합산 최다 월은 3월 3,815건, 최저 월은 12월 950건.
- 시작일·종료일이 유효하고 양 끝 포함 1~366일인 32,942건의 모집기간 중앙값은 19일. 14일 이내는 8,913건(27.1%).
- 공개 CSV는 연간 판본이고 수집 누락·공란이 있을 수 있다. 위 수치는 해당 판본과 집계 규칙의 결과이지 기업마당의 현재 전체 공고 수가 아니다.

## 정책 변화

- [2026년 중기부 추경 확정 발표](https://www.mss.go.kr/site/smba/ex/bbs/View.do?bcIdx=1067187&cbIdx=86&parentSeq=1067187): 1조 6,903억 원과 4개 지원 축을 공식 자료에서 확인.
- [2027년 중기부 예산안 발표](https://www.mss.go.kr/site/smba/ex/bbs/View.do?bcIdx=1070863&cbIdx=86&parentSeq=1070863): 18조 724억 원은 국회 심의 전 정부안. ‘모두의 창업’ 4,411억 원, 지원 규모 2만 명, 단계별 사업화자금 평균 3천만 원도 정부안의 계획값이다.
- 청년창업사관학교의 폐지, 재도전성공학교로의 전환, 신사업창업사관학교·로컬크리에이터 사업의 완전 흡수 및 개별 2027년 접수일은 검증 시점의 공식 모집공고로 확정하지 못했다. 확정 공고나 D-day로 표시하지 않는다.

## localhost:4000 참고 화면의 수치 취급

- 2026-09-20에 참고 사이트 공개 `/api/notices` 응답은 21개 항목(confirmed 10, urgent 5, forecast 6)을 반환했다. 이는 실제 기업마당 전수나 현재 접수 가능 공고 수를 증명하지 않는다.
- 화면의 ‘기업마당 1,529건 연동’, ‘마감임박 124건’, ‘이번 주 신규 204건’은 공개 프런트엔드 번들에 고정 문구로 들어 있다. 공개 API 응답의 21개 항목으로는 재현되지 않는다.
- 참고 사이트의 예측 공고에는 구체적인 2027년 시작·종료일이 붙어 있고, 여러 항목의 링크는 개별 공고문이 아닌 기관 홈페이지다. 이 값들을 확정 일정·공고로 사용하지 않는다.
- 비즈핏은 현재 저장소 공고 수를 동적으로 표시하고, 3개년 과거 통계와 분리한다. 자동 분류한 지역·업종·대상 정보는 자격 확정이 아니라 원문 확인이 필요한 탐색 신호로 표시한다.
